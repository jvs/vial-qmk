  OLED Bitmap Structure

  Display Properties:
  - Resolution: 128x32 pixels total
  - Orientation: Rotated 270° (tall/skinny: 32 pixels wide × 128 pixels tall)
  - Memory Layout: Column-major, 8 pixels per byte (vertical)

  Bitmap Format:
  - Size: 64 bytes total (8 bytes wide × 8 rows)
  - Each byte: Represents 8 vertical pixels
  - Bit 0: Top pixel, Bit 7: Bottom pixel
  - 0x00: All pixels off, 0xFF: All pixels on

  How to Read the Bitmap:

  Let's decode large_M:
  static const char PROGMEM large_M[] = {
      // Row 1 (top 8 pixels of each column)
      0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
      0xFF, 0xFF, 0xFF, 0x1F, 0x3E, 0x7C, 0xF8, 0x7C,
      0x3E, 0x1F, 0xFF, 0xFF, 0xFF, 0x00, 0x00, 0x00,
      0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,

      // Row 2 (bottom 8 pixels of each column)
      0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
      0xFF, 0xFF, 0xFF, 0x00, 0x00, 0x00, 0x01, 0x00,

      0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00
  };

  Byte Value Examples:

  - 0x00 = 00000000 = ░░░░░░░░ (all off)
  - 0xFF = 11111111 = ████████ (all on)
  - 0x1F = 00011111 = ░░░█████ (bottom 5 on)
  - 0x3E = 00111110 = ░████████░ (middle 5 on)
  - 0x7C = 01111100 = ░██████░░ (middle 6 on)

  Creating Serif Fonts:

  To make serif letters, you'd add small horizontal strokes at the ends. For example, a serif "M" might have:
  - Horizontal serifs at the base (bottom pixels)
  - Small flourishes at the top corners

  Tools to help:
  1. Grid paper - Draw 32×16 pixel grid
  2. Online bitmap editor - Convert images to hex
  3. Manual calculation - Each byte = 8 vertical pixels

  void render_stacked_letters(const char* letters[], int count) {
